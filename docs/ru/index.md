# Документация Lemmary {#lemmary-docs}

Руководства по установке и эксплуатации Lemmary.

- [Скриншоты](/ru/screenshots) — обзор всех экранов, от мастера первоначальной настройки до Deep Research
- [Deep Research](/ru/deep_research) — задайте архиву вопрос и получите ответ со ссылками на источники; во что обходится широкий запрос
- [Lemmary, Paperless-ngx и Papra](/ru/comparison) — сравнение по назначению, OCR, ИИ, совместному доступу, автоматизации, шифрованию и лицензированию
- [Самостоятельный хостинг с Docker](/ru/self_hosting) — образ, тома, прокси, резервные копии, обновления
- [Пошаговая настройка ИИ-провайдеров](/ru/guided_ai_setup) — бесплатный ключ Mistral для OCR и эмбеддингов, Opencode Go для языковой модели
- [Руководство по настройке](/ru/setup) — переменные окружения, первый запуск, функции и устранение неполадок
- [Среда разработки](/ru/development) — требования к хосту, FAISS и запуск из исходного кода
- [Хранение данных](/ru/storage) — где находятся SQLite, файлы документов (локально или в S3), эмбеддинги и поисковые индексы
- [ИИ-провайдеры и модели](/ru/ai_providers) — выбор провайдера, начальные ключи, привязка моделей
- [Совместимость с API Paperless-ngx](/ru/paperless_ngx) — подключение сторонних клиентов, перенос существующей библиотеки
- [Сканирование с сетевого сканера](/ru/scanning) — сканирование по eSCL/AirScan и как поиск в локальной сети находит устройство
- [Локальное OCR](/ru/local_ocr) — запуск OCR-движка у себя, чтобы сканы никогда не покидали хост
- [Локальные эмбеддинги](/ru/local_embeddings) — запуск модели эмбеддингов у себя, чтобы Deep Research не расходовал токены
- [Локальные OCR и эмбеддинги на Mac](/ru/local_ai_macos) — и то и другое на GPU Mac с чипом серии M, нативно, а не в Docker
- [Ключ Google Vision API](/ru/google_vision) — получение ключа Cloud Vision API для OCR
- [Вход через ChatGPT](/ru/chatgpt_login) — чат, извлечение данных и Deep Research по подписке ChatGPT вместо ключа с оплатой за использование
- [Вход через OAuth2 / SSO](/ru/oauth) — включение входа через провайдера на экране входа в приложение
- [Вход по ключу доступа](/ru/passkeys) — вход по отпечатку пальца, лицу или PIN-коду устройства вместо пароля
- [Шифрование хранимых данных](/ru/encryption) — том содержит только шифротекст, и чего это стоит
