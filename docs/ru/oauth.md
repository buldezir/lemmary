# Вход через OAuth2 / SSO {#oauth2-sso-sign-in}

Экран входа отражает всё, что принимает коллекция PocketBase `users`. Включите там
OAuth2-провайдер, и рядом с формой ввода email и пароля появится кнопка
**Продолжить через …** — без пересборки и без переменных окружения.

![Экран входа с кнопкой провайдера рядом с формой пароля](../screenshots/login.png)

---

## Шаг 1. Включите провайдер в PocketBase {#step-1-enable-a-provider-in-pocketbase}

1. Откройте интерфейс администратора PocketBase (пункт **Администрирование** в меню
   **Ещё** приложения или `/_/` на сервере) и войдите под учётной записью администратора,
   созданной при настройке.
2. Перейдите в **Collections → users → Options → OAuth2**.
3. Включите **Enable** и добавьте провайдер (Google, GitHub, OIDC, …).
4. Заполните **Client ID** и **Client secret** из консоли провайдера и
   зарегистрируйте у этого провайдера URL перенаправления PocketBase:

   ```
   https://<your-app-host>/api/oauth2-redirect
   ```

5. Сохраните коллекцию, затем перезагрузите экран входа в приложение.

Каждый включённый провайдер получает собственную кнопку с отображаемым именем провайдера.
Вход выполняется во всплывающем окне; приложение подхватывает сессию, как только окно закрывается.

---

## Шаг 2. Создайте для учётной записи запись пользователя {#step-2-give-the-account-a-user-record}

У коллекции `users` нет правила создания — в этом приложении нет самостоятельной регистрации, — поэтому
через OAuth2 можно войти в учётные записи, которые **уже существуют**, но нельзя создать новые.
PocketBase сопоставляет email от провайдера с существующими записями `users`, поэтому:

- Учётная запись администратора, созданная при настройке, может сразу входить через OAuth2,
  если у учётной записи провайдера тот же адрес электронной почты.
- Для всех остальных сначала создайте пользователя: **Collections → users → New record**, с
  адресом электронной почты, который сообщит эта учётная запись провайдера. Заданный там пароль
  для входа через OAuth2 никогда не используется.

Учётная запись без соответствующей записи в `users` получает от PocketBase `Failed to authenticate.`,
и экран входа сообщает об этом вместе с этой подсказкой.

## Дополнительно: только OAuth2 {#optional-oauth2-only}

Если отключить **Identity/password** в **Collections → users → Options**, форма ввода email
и пароля скрывается и остаются только кнопки провайдеров. Сначала учтите две вещи:

- У администраторов остаётся вход через интерфейс администратора PocketBase по адресу `/_/`,
  который выполняет аутентификацию по `_superusers` и от этой настройки не зависит.
- Приложение всё равно показывает форму пароля, если отключить identity/password *и* не оставить
  ни одного включённого OAuth2-провайдера, так что эта настройка не может заблокировать вход для всех.

## См. также {#see-also}

[Вход по ключу доступа](/ru/passkeys) — вход по отпечатку пальца, лицу или PIN-коду устройства вместо
пароля. Он не требует внешнего провайдера и работает вместе с OAuth2 и формой пароля.
Учтите: если отключить identity/password, ключ доступа считается способом входа — Lemmary откажется
удалять последний ключ доступа учётной записи, если другого способа не остаётся.
