# Lemmary Local AI на Linux {#lemmary-local-ai-on-linux}

[Lemmary Local AI](https://github.com/buldezir/lemmary-local-ai) для Linux
запускает эмбеддинги, OCR и, по желанию, текстовую модель для Lemmary на машине
с GPU NVIDIA, поэтому документы не покидают вашу сеть. Это одна программа или
образ Docker с тем же API, что и у [приложения для Mac](/ru/local_ai_macos), так
что Lemmary может переходить между ними, не вычисляя эмбеддинги архива заново.

**[Скачать последнюю версию](https://github.com/buldezir/lemmary-local-ai/releases/latest)**

## Что оно отдаёт {#what-it-serves}

Все три работают на одном порту, `5001`, за одним OpenAI-совместимым `/v1`:

| Задача | Модель | Движок |
| --- | --- | --- |
| Эмбеддинги | `BAAI/bge-m3` | llama.cpp на GPU |
| OCR | `lightonocr-2` | LightOnOCR-2 1B на llama.cpp, по две страницы за раз |
| Извлечение данных (по желанию) | Gemma 4 E4B на GPU с 16 ГБ или модель побольше на 24 ГБ | третий llama.cpp |

При первом запуске оно скачивает и проверяет модели и перезапускает
остановившийся llama.cpp.

Текстовая модель предназначена для извлечения данных (название, дата, тип,
корреспондент, теги, краткое содержание). Извлечение выполняется на модели
**Основного ИИ**, которая также отвечает в «Спросить ИИ» и в поиске с помощью ИИ,
а модель такого размера слабо работает с инструментами и длинными диалогами,
которые там нужны. Поэтому, выбрав её как Основной ИИ, вы отдаёте ей и чат, а
оставив чат на облачной модели, оставляете там и извлечение. В обоих случаях
**Продвинутую** модель для Deep Research лучше взять облачную.

## Требования {#requirements}

- GPU NVIDIA с драйвером 570 или новее. Около 5 ГБ видеопамяти для эмбеддингов и
  OCR; текстовой модели нужен GPU с 16 или 24 ГБ в зависимости от модели.
- Docker с доступом к GPU или, без Docker, дистрибутив с glibc 2.38 или новее,
  например Ubuntu 24.04 или Debian 13.
- OCR занимает около 3,6 с на страницу, так что `OCR_TIMEOUT_SEC` в Lemmary
  (90 с) хватает примерно на 25 страниц; для более длинных документов увеличьте его.

```bash
docker run --gpus all -p 5001:5001 -v lemmary-local-ai:/data \
  ghcr.io/buldezir/lemmary-local-ai:latest -text-model gemma-4-e4b
```

## В Lemmary {#in-lemmary}

В **Админ-панель → ИИ → Провайдеры** добавьте один провайдер типа
**Lemmary Local AI**:

- базовый URL: `http://<host>:5001/v1`;
- без API-ключа.

Затем привяжите модели в **Админ-панель → ИИ → Модели**. Каждый выбор показывает
только модели для своей задачи: `BAAI/bge-m3` для эмбеддингов, `lightonocr-2`
для OCR и текстовую модель, пока она включена, для Основного ИИ.

При первом запуске вариант **Полностью локально** в мастере настройки делает и
то и другое: спрашивает только адрес и открывает шаг выбора моделей со всеми
тремя привязками.

В [README](https://github.com/buldezir/lemmary-local-ai/blob/main/linux/README.md)
описаны настройки, запуск без Docker или как службы systemd, а также сравнение
моделей OCR и текстовых моделей.
