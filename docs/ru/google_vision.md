# Ключ Google Cloud Vision API {#google-cloud-vision-api-key}

Получение ключа Google Cloud Vision API требует нескольких определённых шагов в Google Cloud Console. Поскольку Vision API — платный сервис (хотя и с щедрым бесплатным уровнем в 1000 бесплатных запросов в месяц), для его активации понадобится настроить платёжный аккаунт.

Ниже — пошаговое руководство по созданию и защите ключа API.

---

## Шаг 1. Создайте проект Google Cloud {#step-1-create-a-google-cloud-project}

Все API Google Cloud должны быть привязаны к конкретному проекту для учёта, квот и оплаты.

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Войдите со своим аккаунтом Google.
3. На верхней панели слева (рядом с логотипом «Google Cloud») нажмите меню **Project Dropdown**.
4. Во всплывающем окне в правом верхнем углу нажмите **New Project**.
5. Введите **Project Name** (например, `My-Vision-App`) и нажмите **Create**.
6. Подождите несколько секунд, пока проект будет создан, затем убедитесь, что он выбран в верхнем раскрывающемся меню.

---

## Шаг 2. Настройте платёжный аккаунт {#step-2-set-up-a-billing-account}

Для активации Vision API Google требует привязанный платёжный аккаунт, даже если вы не выходите за пределы бесплатного уровня.

1. Нажмите **Navigation Menu** (значок из трёх горизонтальных линий, «гамбургер», в левом верхнем углу).
2. Выберите **Billing**.
3. Если платёжного аккаунта у вас нет, нажмите **Link a billing account** или **Create account**.
4. Следуйте подсказкам: укажите страну, профиль и действующую кредитную карту.

> **Примечание:** новые аккаунты получают от Google пробный кредит в $300, и деньги не списываются, пока вы не перейдёте с Free Tier на платный тариф

---

## Шаг 3. Включите Cloud Vision API {#step-3-enable-the-cloud-vision-api}

Теперь, когда к проекту привязана оплата, нужно включить саму функциональность Vision.

1. Откройте Navigation Menu и перейдите в **APIs & Services** > **Library**.
2. В строке поиска введите **Cloud Vision API** и нажмите Enter.
3. Нажмите на результат **Cloud Vision API**.
4. Нажмите синюю кнопку **Enable**. (Это может занять некоторое время.)

---

## Шаг 4. Создайте ключ API {#step-4-generate-your-api-key}

Когда API включён, можно создать сами учётные данные.

1. Вернитесь в Navigation Menu и выберите **APIs & Services** > **Credentials**.
2. Нажмите кнопку **+ Create Credentials** в верхней части экрана.
3. Выберите **API key** в раскрывающемся списке.
4. Появится всплывающее окно с вашим новым ключом API (длинная строка из букв и цифр).
5. Скопируйте этот ключ в буфер обмена. Вставьте его в **Настройки → Провайдеры** как провайдер `google_vision` или в `.env` перед первым запуском как `OCR_API_KEY=` вместе с `OCR_SDK=google_vision`.
